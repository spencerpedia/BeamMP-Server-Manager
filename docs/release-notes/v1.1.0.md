# BeamMP Server Manager 1.1.0

Adds optional Discord notifications. Paste a webhook into a server's settings and the panel posts what's happening on that server to a Discord channel.

## New: Discord notifications

Open a server's **Settings** tab and find the new **Discord notifications** card:

1. In Discord, go to **Edit channel → Integrations → Webhooks → New Webhook** and copy the webhook URL.
2. Paste it into the card, turn notifications on, and click **Save**.
3. Click **Send test message** to check that it works.

You can turn each type of message on or off:

- **Server status:** started (with the BeamMP version), stopped, crashed, failed to start, and auto-restart giving up after 3 crashes in 5 minutes
- **Player join/leave:** for example "**Ann** joined (3/8)"
- **Schedules & backups:** the result of every scheduled task (failures in red), plus manual backups and restores, with who ran them

Good to know:

- **Off by default.** Nothing is posted until a server has a webhook saved and turned on.
- **Per server.** Each server has its own settings, so different servers can post to different channels or share one. Settings aren't copied when you clone a server or save it as a template.
- **Operators and admins only.** Only operators and admins of a server can see or change its webhook, because the URL works like a password.
- **No pings.** Messages never ping anyone (no @everyone or role mentions), and player names are escaped so they can't break the formatting.
- **Rate limits.** Events that happen within a couple of seconds of each other are sent as one message, and the panel waits if Discord rate-limits it.
- **Restarts.** A restart posts "stopped" and then "started". Stopping the container doesn't post anything.

## Fixes

- Outgoing HTTP requests are no longer logged line by line, so webhook URLs and other request URLs stay out of the container logs.

## Upgrading

On Unraid, use **apply update** in the Docker tab. With Compose, run `docker compose pull && docker compose up -d`. The database updates itself on first start.

```
ghcr.io/spencerpedia/beammp-server-manager:1.1.0
```
