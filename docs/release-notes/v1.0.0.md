# BeamMP Server Manager 1.0.0

The first release of a self-hosted web panel for [BeamMP](https://beammp.com) servers. Run any number of BeamMP servers in one Docker container and manage them from your browser.

![Dashboard](https://raw.githubusercontent.com/spencerpedia/BeamMP-Server-Manager/v1.0.0/docs/screenshots/dashboard.png)

## Features

**Server management**
- Run multiple BeamMP servers side by side, each with its own port, config, mods and plugins
- Start, stop, restart and force-kill, with clean shutdowns
- Automatic restart after a crash (up to 3 times in 5 minutes), plus an option to start with the panel
- BeamMP-Server binaries download automatically from GitHub; follow "latest" or pin a version per server

**Console & config**
- Live console in the browser with command history and quick commands
- `ServerConfig.toml` form with a map picker and a hidden auth key, plus a raw TOML editor that keeps comments

**Mods, maps & plugins**
- Drag-and-drop mod uploads with enable/disable; maps inside mod zips are detected automatically
- **BeamNG.com mod browser:** browse by category and sort order, install by link, check for updates
- **Plugin browser:** featured plugins (BeamJoy, CobaltEssentials, Nickel and more) plus GitHub search, with automatic layout detection

**Players**
- Live player list, kicks, and bans by name, BeamMP ID or IP (enforced at join)
- Chat log, and a box to message all players as Server

**Automation & safety**
- Cron schedules for restarts, backups, console commands and updates, with optional in-game countdown warnings
- One-click backups with retention, download and restore
- CPU, RAM and player-count graphs

**Templates & import**
- Save a server as a template, create servers from templates, clone servers, and export/import templates as `.zip`
- Import existing BeamMP server folders, including ich777's BeamNG-MP container layout
- Mod zips are hard-linked between servers and templates on the same disk, so copies take almost no space

**Users**
- Admin, operator and viewer roles with per-server access
- Audit log of every action

## Install

**Docker image** (amd64 + arm64):

```
ghcr.io/spencerpedia/beammp-server-manager:1.0.0
```

**Docker Compose:** download [`docker-compose.yml`](https://github.com/spencerpedia/BeamMP-Server-Manager/blob/v1.0.0/docker-compose.yml) and run `docker compose up -d`.

**Unraid:**

```sh
wget -O /boot/config/plugins/dockerMan/templates-user/my-BeamMP-Server-Manager.xml \
  https://raw.githubusercontent.com/spencerpedia/BeamMP-Server-Manager/v1.0.0/unraid-template.xml
```

Then go to **Docker → Add Container → BeamMP-Server-Manager**.

Open the panel on port `8000` (or whichever port you mapped), create your admin account, and add a server with an auth key from [keymaster.beammp.com](https://keymaster.beammp.com).

## Good to know

- Each BeamMP server needs one port open on **both TCP and UDP**. The default range is `30814-30823` (10 servers). Forward those ports on your router so players outside your network can join.
- Keyword search for BeamNG.com mods isn't available, because their search is behind a bot check. Search on beamng.com and paste the link into the mod browser instead.
- Game servers stop when the container stops. Enable **Start with the panel** on any server that should come back up automatically.
- Player tracking and bans work through a small bridge Lua plugin (`_BMSM`) that the panel installs into each server.
